02 · ENTENDA A IDEIA

Uma troca que não muda nada.

Um anagrama é uma reorganização de todas as letras de uma palavra, mesmo que o resultado não tenha significado.

GUARDE ESTA IDEIA

Conte tudo.
Corrija as repetições.

No numerador, contamos como se todas as letras fossem diferentes. No denominador, retiramos as trocas entre letras iguais.

P = n!r₁! × r₂! × … × rₖ!

n é o total de elementos.
r₁, r₂, …, rₖ são as quantidades de cada elemento repetido.

Há mais de uma letra repetida? Multiplique os fatoriais das repetições no denominador.
